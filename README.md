# K-REMS (신재생통합관리시스템)

한국수력원자력(KHNP) 신재생에너지 통합 관리 시스템 웹 애플리케이션입니다. 
태양광, 풍력 등 신재생 발전소의 실시간 모니터링, 발전분석, 정비이력, 수익분석, 보고서 및 시스템 관리 기능을 제공합니다.

## 주요 기능

- **통합 대시보드**: 전국 발전소 현황, 실시간 발전량, 누적 발전량 등 주요 KPI 요약
- **TV 대시보드**: TV-통합 / TV-1 종합발전정보 / TV-2 자체설비 / TV-3 출력현황
- **발전분석**: 발전이력, 알람이력, 예측분석, 정밀분석
- **정비이력**: 장애등록, 예방정비, 이력조회
- **수익분석**: 매출관리, 비용관리(12개 세목), 수익분석
- **보고서**: 발전현황, 정비이력, 수익요약 리포트
- **관리(Admin)**: 발전소/그룹/사용자/알람 설정 (시스템관리자 권한)

## 기술 스택

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Recharts (차트)
- React Router (라우팅)

## 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

## 프로젝트 구조

```
src/
  components/     # 공통 컴포넌트 (Sidebar, Header, Charts 등)
  pages/          # 페이지 컴포넌트 (Dashboard, Report, Admin 등)
  data/           # Mock 데이터 및 상수
  hooks/          # 커스텀 React 훅
  lib/            # 유틸리티 함수
```
